# ISO Guide - 消防安全官戰術指揮與教育訓練儀表板

本專案是一個專為消防安全官（Incident Safety Officer, ISO）設計的網頁端戰術指揮與現場決策輔助工具。本版本已針對**行動端進行優化（Mobile-First Redesign）**，並擴充了 Dave Dodson 的火煙判讀學說及 NFPA 1521/1550 職責規範，旨在提供適合手機、平板及桌機跨螢幕流暢閱讀與操作的優質體驗。

## 📱 行動端與排版優化特點

1. **北歐戰術深色主題 (Nordic Tactical Dark)**：優化了背景、文字與卡片的色彩對比度，即使在戶外烈日下也具備極佳的視覺可讀性。
2. **雙軌導覽切換系統**：
   - **桌面端**：保留左側功能完整的 sticky 側邊欄。
   - **行動端**：底端懸浮式快捷導覽列（App 原生質感），操作按鈕與輸入滑桿均調整為大於 44px 的友善觸控尺寸。
3. **Plus Jakarta Sans 字體**：全面升級網頁字體，使段落間距、行高 (`line-height: 1.625`) 在手機螢幕呈現上更加通順、不刺眼。

## 🚀 核心功能與新增內容

- **儀表板 (Dashboard)**：即時滾動警示跑馬燈、歷史火警殉職案例的戰術失誤分析（喬友、敬鵬）。
- **安全官職責檢核 (NFPA 1521)**：新增依照到達評估、危害辨識、安全區域設置、後勤與 RIC 管制等階段設計的實用檢核清單。
- **MEDIC 量化計算器**：
  - **SPE 風險量化計算機**：自動依據現場「人命待救價值」對照 81/51 安全界線，提示戰術防禦或進攻命令。
  - **VTS (Value, Time, Size) 評估器** 與 **危害優先級 5x5 矩陣**。
- **VVDC 火煙深度判讀 (Dave Dodson)**：
  - 詳細解說煙霧體積、流速（湍流與閃燃前兆）、密度（燃料飽和度）與顏色的變化意涵。
  - **流動路徑 (Flow Path) 安全管制**：人員禁止佔據出風口，且風向通風須同步防阻爆燃。
- **生理監測 (REHAB)**：20分鐘氣瓶休息定時提醒、水分與稀釋運動飲料（1:1）補充估算器。
- **緊急自救 (GRAB LIVES)**：手機版易讀的步驟式 MAYDAY 自救實踐工具。
- **化災專區**：NFPA 704 化學品符號自動生成與 LNG 蒸氣雲爆炸 (VCE) 謝爾金效應安全半徑估算器。

## 🛠️ 技術架構

- **前端技術**：HTML5, Tailwind CSS, Vanilla JS
- **排版字型**：Plus Jakarta Sans (Body), JetBrains Mono (Metrics & Code)
- **部署位置**：GitHub Pages 靜態網站託管 (部署於 `ISO-guide` 儲存庫)
